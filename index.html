Projects

CommUnity Hub

The CommUnity Hub was a barangay management system built for Barangay Seselangen in Sual Pangasinan. The system was built to help the barangay officials in managing the barangay's information and records. And the system was built using C# programming language and MySQL database.

CommUnity Hub Manuscript

The CommUnity Hub Manuscript is a thesis paper that contains the details of the CommUnity Hub project. The manuscript includes a comprehensive overview of the system's design, development process, and implementation. It highlights the system's features, such as user management, record tracking, and report generation. Additionally, the manuscript provides insights into the challenges faced during development and the solutions implemented. The document was created using Microsoft Word and was submitted to STI Alaminos as part of the academic requirements. It serves as a valuable resource for understanding the technical and functional aspects of the CommUnity Hub system.
